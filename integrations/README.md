# Intégrer les données de Polradar

Le client JavaScript interroge l’API publique en lecture seule. Il utilise le `fetch` natif et conserve les champs de provenance et de révision. Depuis la racine du dépôt, lancez `node integrations/javascript/exemple.mjs chiffrement`.

Le SDK et l’exemple sont sous [MIT](LICENSE). Les données reçues conservent le régime de la [base et de leurs sources](https://polradar.fr/licences/).
