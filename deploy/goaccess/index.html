Périmètre du rapport

GoAccess agrège les seuls journaux HTTPS dédiés à Polradar. La collecte commence à l’activation de ce journal. Le rapport est recalculé toutes les 15 minutes à partir des fichiers encore disponibles, avec 14 rotations quotidiennes conservées.

Les requêtes incluent les ressources, les erreurs et les passages automatisés. Les comptages de profils quotidiens GoAccess reposent sur l’adresse, l’agent utilisateur et le jour ; un même client peut être compté plusieurs jours. Les IP, les agents utilisateurs bruts et les paramètres d’URL ne sont pas publiés dans ce rapport. Les visites de cette interface sont exclues du journal dédié.
