Périmètre du rapport

GoAccess agrège les seuls journaux HTTPS dédiés à Polradar. La collecte commence à l’activation de ce journal. Le rapport est recalculé toutes les 15 minutes à partir des fichiers encore disponibles, avec 14 rotations quotidiennes conservées.

Les requêtes incluent les ressources, les erreurs et les passages automatisés. Les visiteurs uniques GoAccess sont dédupliqués par adresse IP, agent utilisateur et jour. Le total sur plusieurs jours cumule les uniques journaliers ; il ne compte pas des personnes distinctes. Le filtre « hors robots reconnus » conserve les robots non identifiés. Les IP, les agents utilisateurs bruts et les paramètres d’URL ne sont pas publiés dans ce rapport. Les visites de cette interface sont exclues du journal dédié.
